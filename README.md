# Maison Vineet — Android App

Android wrapper for the Maison Vineet Real Skin Analysis PWA.

## Build
Open this project in Android Studio, or push it to GitHub and run:
**Actions → Build Maison Vineet Android App → Run workflow**.

The workflow produces `app-debug.apk` as a downloadable artifact.

Application ID:
`com.maisonvineet.realanalysis`
